## Comment utiliser ce document

- Un plan par ligne : identifiant, timecode, durée, méthode, lieu, état du pont, narration, description visuelle, caméra, prompt d'image et notes.
- La couleur de la première colonne indique la méthode : gris = noir ou texte, bleu = Blender, vert = image IA animée avec Seedance, jaune = motion graphics, orange = photo réelle (licence à vérifier).
- Priorité B = plan coupable si la vidéo dépasse la durée voulue. Les durées se calculent ainsi : mots de la narration ÷ débit de la voix + pause ; les plans sans narration ont une durée imposée.
- Quand une narration couvre plusieurs plans, elle est écrite sur le premier plan et rappelée dans ses notes.
- Pour chaque prompt d'image, ajoutez le préfixe de style et la liste « à éviter » de la section Style, afin que toutes les images restent cohérentes.
- Les noms de fichiers image sont prévus pour que l'agent associe chaque image à son plan.
