# 🏛️ Composant : Forensic 3D Cross-Section Schematic (Diorama & Écorché de Braquage)

Ce composant génère des plans 3D en **coupe transversale schématique (*Cross-Section Diorama*)** pour visualiser des opérations complexes : tunnels de braquage, passages secrets, circuits de fuite, structures de bâtiments ou coffres-forts sous la ville.

---

## 🎯 Quand l'utiliser ?

* 🔹 Révélation d'un mode opératoire souterrain (ex : le casse de la Banco Central de Fortaleza, 80m de tunnel).
* 🔹 Coupe technique d'un bâtiment ou d'une infrastructure inviolable.
* 🔹 Mise en scène d'une trajectoire cachée sous le trafic urbain.
* 🔹 Plan d'explication "Forensic Blueprint / Clay Render" cinématique.

---

## 📸 Rendu Obtenu

Le plan combine :
1. **La surface urbaine** : Maison de départ, rue avec trafic et lampadaires, immeubles et Banque Centrale avec colonnades.
2. **Le sous-sol écorché** : Piliers en béton armé, fondations, chambre forte avec porte blindée ronde en acier.
3. **Le tunnel néon cyan** : Trajet tubulaire lumineux traversant 80 mètres de sous-sol avec particules scintillantes.
4. **L'habillage HUD Blueprint** : Titre en haut à gauche, lignes de cotes avec pastilles lumineuses, repères textuels et badge de métriques (*DISTANCE: 80 METERS / DEPTH: 6 METERS*).

---

## 💻 Génération & Script

Le script de génération automatique pour Blender est prêt à l'emploi :

```bash
# Exécution directe dans Blender via python
.venv/bin/python scripts/generate_cross_section_schematic.py
```

Ou directement pilotable via le serveur **MCP Blender** dans Antigravity.
